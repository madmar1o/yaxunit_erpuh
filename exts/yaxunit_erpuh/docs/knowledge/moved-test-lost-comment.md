# Перенесённый тест потерял описание и получил замечание EDT

**Симптом.** После переноса теста из другого расширения EDT показывает замечание
`export-procedure-missing-comment` («отсутствует комментарий к экспортной процедуре»), а в TDD-документе
у теста пропало требование — остались только шаги. Сам тест при этом работает.

**Причина.** Перенос делался по тексту процедуры: от строки `Процедура ...` до `КонецПроцедуры`. Но
описание теста в этом модуле — комментарий **над** процедурой, и он в перенос не попал. Требование
из doc-комментария формирует и спецификацию, и замечание EDT, поэтому тест остался без описания.

**Решение.** Переносить тест вместе с комментарием над ним: вырезать от начала блока комментариев
(`//`) до `КонецПроцедуры`. Отдельно проверить:

- комментарий идёт вплотную над `Процедура`, без пустой строки;
- у процедуры с параметрами в комментарии есть секция «Параметры:» — иначе EDT добавит
  `doc-comment-parameter-section`;
- в тестовых методах с параметрами-коллекциями тип указывается полностью: «Массив из Строка», а не
  «Массив» (`doc-comment-collection-item-type`);
- перенос выполняется одним файлом целиком (правка на диске), после чего проект перечитывается EDT.

**Как проверили.** После восстановления комментария и дополнения секций «Параметры:» в тестовом модуле
осталась ровно одна категория замечаний EDT — 54 `undefined-variable` на модулях движка (см.
[`edt-undefined-variable-engine.md`](edt-undefined-variable-engine.md)); замечаний стиля в модуле нет.
Прогон после правок — 51 / 51 PASSED.
